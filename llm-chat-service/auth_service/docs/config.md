# Конфигурация приложения

Файл с переменными окружения .env должен располагаться в корневой директории проекта — на том же уровне, где находится 
основной исполняемый модуль или точка входа в приложение.

**Шаблон файла:**

```
# === Приложение ===
APP_NAME=
ENV=

# === JWT настройки ===
JWT__ALG=
JWT__TOKEN_TYPE=

# Ключ для подписи access токена (заполняется один из следующих параметров):
JWT__ACCESS_SECRET__DATA=
JWT__ACCESS_SECRET__PATH=

# Ключ для подписи куакуыр токена (заполняется один из следующих параметров):
JWT__REFRESH_SECRET__DATA=
JWT__REFRESH_SECRET__PATH=

JWT__ACCESS_TOKEN_EXPIRE_MINUTES=
JWT__REFRESH_TOKEN_EXPIRE_HOURS=

# === Подключение к БД ===

DB__HOST=
DB__PORT=
DB__DB_NAME=
DB__USER=
DB__PASSWORD=
DB__DB_SCHEMA=
DB__DB_TYPE=

# Для тестирования на SQLite:
DB__DB_PATH=

# === Хэширование паролей ===
PASSWORD_HASH__SCHEMAS=
PASSWORD_HASH__BCRYPT=

# === Настройки CORS ===
CORS__ENABLED=
CORS__ORIGINS=
CORS__METHODS=
CORS__HEADERS=
CORS__CREDENTIALS=
```

## Основные настройки

| Параметр   | Тип      | Обязательный | Значение по умолчанию | Описание                              |
|------------|----------|--------------|-----------------------|---------------------------------------|
| `APP_NAME` | `string` | Нет          | `"Auth Service"`      | Название сервиса                      |
| `ENV`      | `string` | Нет          | `"prod"`              | Окружение выполнения (prod/dev/test)  |

## Настройки JWT

| Параметр                           | Тип       | Обязательный | Значение по умолчанию   | Описание                                                                |
|------------------------------------|-----------|--------------|-------------------------|-------------------------------------------------------------------------|
| `JWT__ALG`                         | `string`  | Нет          | `"HS256"`               | Алгоритм подписи JWT токенов                                            |
| `JWT__TOKEN_TYPE`                  | `string`  | Нет          | `"bearer"`              | Тип токена для авторизации                                              |
| `JWT__ACCESS_SECRET__DATA`         | `string`  | Да           | `-`                     | Секретный ключ для подписи access токена (в виде строки)<sup>*</sup>    |
| `JWT__ACCESS_SECRET__PATH`         | `string`  | Да           | `-`                     | Путь к файлу с секретным ключом для подписи access токена<sup>*</sup>   |
| `JWT__REFRESH_SECRET__DATA`        | `string`  | Да           | `-`                     | Секретный ключ для подписи refresh токена (в виде строки)<sup>**</sup>  |
| `JWT__REFRESH_SECRET__PATH`        | `string`  | Да           | `-`                     | Путь к файлу с секретным ключом для подписи refresh токена<sup>**</sup> |
| `JWT__ACCESS_TOKEN_EXPIRE_MINUTES` | `integer` | Нет          | `15`                    | Время жизни access токена в минутах                                     |
| `JWT__REFRESH_TOKEN_EXPIRE_HOURS`  | `integer` | Нет          | `24`                    | Время жизни refresh токена в часах                                      |

<sup>*</sup>Требуется указать один из параметров: `JWT__ACCESS_SECRET__DATA`/`JWT__ACCESS_SECRET__PATH`. Если указаны 
оба будет использоваться `JWT__ACCESS_SECRET__DATA`.

<sup>**</sup>Требуется указать один из параметров: `JWT__REFRESH_SECRET__DATA`/`JWT__REFRESH_SECRET__PATH`. Если 
указаны оба будет использоваться `JWT__REFRESH_SECRET__DATA`.

## Настройки подключения к БД

| Параметр        | Тип       | Обязательный | Значение по умолчанию | Описание                                  |
|-----------------|-----------|--------------|-----------------------|-------------------------------------------|
| `DB__HOST`      | `string`  | Да           | `-`                   | Хост базы данных                          |
| `DB__PORT`      | `integer` | Да           | `-`                   | Порт базы данных                          |
| `DB__DB_NAME`   | `string`  | Да           | `-`                   | Имя базы данных                           |
| `DB__USER`      | `string`  | Да           | `-`                   | Пользователь базы данных                  |
| `DB__PASSWORD`  | `string`  | Да           | `-`                   | Пароль пользователя базы данных           |
| `DB__DB_SCHEMA` | `string`  | Нет          | `"public"`            | Схема базы данных                         |
| `DB__DB_TYPE`   | `string`  | Нет          | `"postgres"`          | Тип базы данных (`postgres` или `sqlite`) |
| `DB__DB_PATH`   | `string`  | Нет          | `None`                | Путь к тестовой базе данных SQLite        |

## Настройки хэширования паролей

| Параметр                 | Тип       | Обязательный | Значение по умолчанию | Описание                                                     |
|--------------------------|-----------|--------------|-----------------------|--------------------------------------------------------------|
| `PASSWORD_HASH__SCHEMAS` | `string`  | Нет          | `"bcrypt"`            | Список используемых схем хеширования паролей (через запятую) |
| `PASSWORD_HASH__BCRYPT`  | `integer` | Нет          | `12`                  | Количество раундов для bcrypt хеширования (от 4 до 31)       |

## Настройки CORS 

| Параметр            | Тип       | Обязательный | Значение по умолчанию | Описание                                        |
|---------------------|-----------|--------------|-----------------------|-------------------------------------------------|
| `CORS__ENABLED`     | `boolean` | Нет          | `true`                | Включение/выключение CORS политики              |
| `CORS__ORIGINS`     | `string`  | Нет          | `"*"`                 | Список разрешенных источников (через запятую)   |
| `CORS__METHODS`     | `string`  | Нет          | `"*"`                 | Список разрешенных HTTP методов (через запятую) |
| `CORS__HEADERS`     | `string`  | Нет          | `"*"`                 | Список разрешенных заголовков (через запятую)   |
| `CORS__CREDENTIALS` | `boolean` | Нет          | `true`                | Разрешить отправку куки/учетных данных          |
