# Конфигурация приложения

**Шаблон файла:**

```dotenv
# === Настройки приложения ===
APP_NAME=
ENV=

# === Настройки логирования ===
LOGS__FILE_PATH=
LOGS__LEVEL=
LOGS__ROTATION=

# === Настройки CORS ===
CORS__ENABLED=
CORS__ORIGINS=
CORS__METHODS=
CORS__HEADERS=
CORS__CREDENTIALS=

# === Настройки сервиса авторизации ===
AUTH_SERVICE__PROTOCOL=
AUTH_SERVICE__HOST=
AUTH_SERVICE__PORT=
AUTH_SERVICE__TIMEOUT=

# === Настройки сервиса чата ===
CHAT_API_SERVICE__PROTOCOL=
CHAT_API_SERVICE__HOST=
CHAT_API_SERVICE__PORT=
CHAT_API_SERVICE__TIMEOUT=

# === Настройки кук авторизации ===
AUTH_COOKIE__ACCESS_TOKEN_COOKIE_NAME=
AUTH_COOKIE__REFRESH_TOKEN_COOKIE_NAME=
AUTH_COOKIE__COOKIE_SECURE=
AUTH_COOKIE__COOKIE_SAME_SITE=

# === Настройки кук пользователя ===
COOKIE__USER_ID_COOKIE_NAME=
COOKIE__USER_EMAIL_COOKIE_NAME=
COOKIE__USER_ROLE_COOKIE_NAME=

# === Настройки Jinja2 ===
JINJA__DIR=

# === Настройки RabbitMQ ===
RABBITMQ__HOST=
RABBITMQ__PORT=
RABBITMQ__USER=
RABBITMQ__PASSWORD=
RABBITMQ__VHOST=

# === Настройки заголовка авторизации ===
AUTH_HEADER_NAME=
```

## Основные настройки

| Параметр   | Тип      | Обязательный | Значение по умолчанию        | Описание                              |
|------------|----------|--------------|------------------------------|---------------------------------------|
| `APP_NAME` | `string` | Нет          | `"Chat API service"`         | Название сервиса                      |
| `ENV`      | `string` | Нет          | `"prod"`                     | Окружение выполнения (prod/dev/test)  |

## Настройки CORS

| Параметр            | Тип       | Обязательный | Значение по умолчанию | Описание                                        |
|---------------------|-----------|--------------|-----------------------|-------------------------------------------------|
| `CORS__ENABLED`     | `boolean` | Нет          | `true`                | Включение/выключение CORS политики              |
| `CORS__ORIGINS`     | `string`  | Нет          | `"*"`                 | Список разрешенных источников (через запятую)   |
| `CORS__METHODS`     | `string`  | Нет          | `"*"`                 | Список разрешенных HTTP методов (через запятую) |
| `CORS__HEADERS`     | `string`  | Нет          | `"*"`                 | Список разрешенных заголовков (через запятую)   |
| `CORS__CREDENTIALS` | `boolean` | Нет          | `true`                | Разрешить отправку куки/учетных данных          |

## Настройки логирования

| Параметр          | Тип      | Обязательный | Значение по умолчанию    | Описание                                                                      |
|-------------------|----------|--------------|--------------------------|-------------------------------------------------------------------------------|
| `LOGS__FILE_PATH` | `string` | Нет          | `"logs/service.log"`     | Путь к файлу для сохранения логов (может быть относительным или абсолютным)   |
| `LOGS__LEVEL`     | `string` | Нет          | `"INFO"`                 | Уровень логирования. Допустимые значения: `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `LOGS__ROTATION`  | `string` | Нет          | `"1 day"`                | Период ротации логов. Форматы: `"X days"`, `"X hours"`, `"X MB"`, `"X GB"`    |

## Настройки сервиса авторизации

| Параметр                 | Тип       | Обязательный  | Значение по умолчанию | Описание         |
|--------------------------|-----------|---------------|-----------------------|------------------|
| `AUTH_SERVICE__PROTOCOL` | `string`  | Нет           | `"http"`              | Протокол сервиса |
| `AUTH_SERVICE__HOST`     | `string`  | Да            | `"127.0.0.1"`         | Хост сервиса     |
| `AUTH_SERVICE__PORT`     | `integer` | Да            | -                     | Порт сервиса     |
| `AUTH_SERVICE__TIMEOUT`  | `integer` | Нет           | `10`                  | Таймаут запроса  |

## Настройки сервиса чата

| Параметр                     | Тип       | Обязательный | Значение по умолчанию | Описание         |
|------------------------------|-----------|--------------|-----------------------|------------------|
| `CHAT_API_SERVICE__PROTOCOL` | `string`  | Нет          | `"http"`              | Протокол сервиса |
| `CHAT_API_SERVICE__HOST`     | `string`  | Да           | `"127.0.0.1"`         | Хост сервиса     |
| `CHAT_API_SERVICE__PORT`     | `integer` | Да           | -                     | Порт сервиса     |
| `CHAT_API_SERVICE__TIMEOUT`  | `integer` | Нет          | `10`                  | Таймаут запроса  |

## Настройки кук авторизации

| Параметр                                 | Тип       | Обязательный | Значение по умолчанию | Описание                    |
|------------------------------------------|-----------|--------------|-----------------------|-----------------------------|
| `AUTH_COOKIE__ACCESS_TOKEN_COOKIE_NAME`  | `string`  | Нет          | `"access_token"`      | Имя куки для access токена  |
| `AUTH_COOKIE__REFRESH_TOKEN_COOKIE_NAME` | `string`  | Нет          | `"refresh_token"`     | Имя куки для refresh токена |
| `AUTH_COOKIE__COOKIE_SECURE`             | `boolean` | Нет          | `true`                | Флаг Secure для кук         |
| `AUTH_COOKIE__COOKIE_SAME_SITE`          | `string`  | Нет          | `"lax"`               | Атрибут SameSite            |

## Настройки кук пользователя

| Параметр                         | Тип      | Обязательный | Значение по умолчанию | Описание                        |
|----------------------------------|----------|--------------|-----------------------|---------------------------------|
| `COOKIE__USER_ID_COOKIE_NAME`    | `string` | Нет          | `"user_id"`           | Имя куки для ID пользователя    |
| `COOKIE__USER_EMAIL_COOKIE_NAME` | `string` | Нет          | `"user_email"`        | Имя куки для email пользователя |
| `COOKIE__USER_ROLE_COOKIE_NAME`  | `string` | Нет          | `"user_role"`         | Имя куки для роли пользователя  |

## Настройки Jinja2

| Параметр     | Тип      | Обязательный | Значение по умолчанию           | Описание                   |
|--------------|----------|--------------|---------------------------------|----------------------------|
| `JINJA__DIR` | `string` | Нет          | `"./web_service/app/templates"` | Путь к директории шаблонов |



## Настройки RabbitMQ

| Параметр                   | Тип       | Обязательный | Значение по умолчанию | Описание                        |
|----------------------------|-----------|--------------|-----------------------|---------------------------------|
| `RABBITMQ__HOST`           | `string`  | Да           | `-`                   | Хост RabbitMQ сервера           |
| `RABBITMQ__PORT`           | `integer` | Да           | `-`                   | Порт RabbitMQ сервера           |
| `RABBITMQ__USER`           | `string`  | Да           | `-`                   | Имя пользователя RabbitMQ       |
| `RABBITMQ__PASSWORD`       | `string`  | Да           | `-`                   | Пароль пользователя RabbitMQ    |
| `RABBITMQ__VHOST`          | `string`  | Нет          | `None`                | Виртуальный хост RabbitMQ       |
| `RABBITMQ__MESSAGE_QUEUE`  | `string`  | Нет          | `message`             | Префикс имени очереди сообщений |

## Настройки заголовка авторизации

| Параметр           | Тип      | Обязательный | Значение по умолчанию | Описание                  |
|--------------------|----------|--------------|-----------------------|---------------------------|
| `AUTH_HEADER_NAME` | `string` | Нет          | `"Authorization"`     | Имя заголовка авторизации |
